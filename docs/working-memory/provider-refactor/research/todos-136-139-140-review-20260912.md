## Shared And Divergent Behavior

- UI 不改组件样式；普通新任务和分享导入共用默认选择规则，但只给首次导入打初始化来源标记。
- ModelSelectionView 仍是有效性来源；已保存草稿的明确空选择和暂时无效选择均不被默认模型填满。
- 导入只产生 Renderer 草稿，不改 Host 原子导入或执行配置提交边界；模型不可用不阻塞打开内容。
- 闲时模型源依旧隐藏，不进入普通任务模型目录；普通 API／套餐／Start 能力不随闲时改变。
- 安全校验准入扩大，但实际是否进入校验仍取决于开关和原有重试、降级，不声称命中域名必然进入校验。

## Must-Preserve Invariants 与复审结论

- Todo136：根域、子域、大小写、路径／端口／query／fragment、假后缀、非法 URL 均覆盖；账号个人／团队和手工套餐 Access 保留独立准入。Start／闲时不再被账号分支提前排除。HTTP 仍由原有安全校验拒绝，未降低传输安全。
- Todo139：初始化只复制配置；Root 正文和 Recent 不动。已有目标草稿、重复导入、历史会话不被重置。Registry 延迟不受空 snapshot 抢占；用户先改模式或模型／档位均不会被迟到默认值覆盖。只有 Renderer 本地标记变化，不增加同步协议或第二份执行状态。
- Todo140：两家精确目录与默认启用状态一致。5.3 无图片／视频；Flash 图片／视频／PDF 保留；均无内置搜索、有 MCS，保留 Anthropic 映射、1M 上下文、128000 输出上限及 low/high/max。旧全局模型规则仍保留。
- 核对 `OffPeakTaskService`：按保存的 ModelSelection 校验／派发，没有依赖 5.2／Turbo 的硬编码；新目录不会把旧任务偷偷切到 5.3。新增型号是否由线上闲时服务实际接受未在本轮联网实测。
